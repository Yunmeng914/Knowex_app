# Knowex Exa 学术搜索

Exa 在 Knowex 中是独立的网页检索与内容抓取模块。初版不会把 Exa 当作 AI 模型，也不会自动调用当前 AI 连接总结网页。

## 开始使用

1. 打开 Exa Dashboard 的 API Keys 页面并创建 API Key。
2. 在 Knowex 右上角打开“设置”。
3. 找到“Exa 学术搜索”，粘贴 API Key，点击“保存 Exa Key”。
4. 点击“测试连接”。测试会执行一次真实搜索，因此会产生一次 Exa 调用。
5. 回到主界面，可以使用工具栏的全局搜索，或从文字选区、框选区域和已有批注进入 Exa。

Exa Key 使用 Electron `safeStorage` 加密并单独保存在应用配置目录的 `exa.json` 中。Key 不会进入工作区、渲染界面或 Exa 搜索结果。

## 三种检索入口

1. **选中文字**：选区旁的快捷栏和右键菜单都提供“用 Exa 检索”。选择后，Knowex 会保存该文字证据并直接展开右侧批注中的 Exa 区域。
2. **框选页面区域**：框选完成后可直接选择 Exa、AI、翻译或复制。图片不能直接作为 Exa 的语义查询，因此选择 Exa 后需要在打开的检索框中补充研究问题；Knowex 不会暗中调用 AI 识图。
3. **已有批注**：打开批注后，可以在“个人学习笔记”“Exa 文献检索”“AI 问答与翻译”三个折叠区之间切换。Exa 会优先使用已选文字；截图批注则使用标题和个人笔记作为辅助上下文。

全局工具栏仍保留“学术搜索”，用于没有特定论文证据时的普通检索。

## 筛选、结果与抓取

- 默认范围是“学术优先”，请求使用 Exa 的 `research paper` 分类，优先返回论文、预印本和学术出版物。需要项目页、官方博客或技术报告时，可以切换“全网内容”。
- “详细筛选”支持起止年份、5/8/10 条结果和语言偏好，默认保持折叠。
- 文献语言支持中文、英文、日文、德文、法文和西班牙文偏好。Exa 当前没有独立的严格语言过滤参数，因此 Knowex 会把语言作为语义偏好加入检索；结果仍可能包含其他语言。
- 每个来源的 highlights 会显示在独立的“原文引用”区域。它们是 Exa 返回的网页片段，不是 AI 总结，也不能替代阅读全文核验。
- “打开原文”会使用系统默认浏览器打开来源。
- “抓取正文”会再次调用 Exa Contents API，获取适合阅读的 Markdown 文本。正文只在当前窗口内暂存；初版尚未写入工作区。

Exa 只会在确认搜索、抓取正文或测试连接时收到请求。右键、打开批注、展开 Exa 区域或输入文字都不会产生调用。提交搜索时，Exa 会收到当前研究问题、可用的文字证据和所选筛选条件；截图图片不会发送给 Exa。

## 怎样搜得更好

不要只输入过于宽泛的单词。建议在查询中包含研究对象、方法、时间、任务或比较指标。

较弱的查询：

```text
RAG
```

更明确的首条指令：

```text
2024 年以来检索增强生成中引用真实性和来源归因的评测方法
```

```text
peer-reviewed comparisons of LoRA and full fine-tuning for medical large language models
```

使用建议：

- 学术主题优先保留“学术优先”。
- 先选中范围尽可能准确的论文原文，再在检索框说明希望寻找“支持、反驳、复现、综述、方法比较”中的哪一种证据。
- 结果不足时，在检索框补充论文中的英文术语，再考虑放宽年份或切换全网内容。
- 同时比较多个来源，不要把一个“原文引用”片段当作完整结论。
- 找不到论文时，可临时切换“全网内容”，用于寻找官方项目页、实验室博客或技术报告。

## 初版限制

- 不保存检索结果和正文。
- 不调用 AI 总结网页。
- 不支持 Exa Deep Search、Agent、Monitors 或后台搜索。
- 不自动生成论文引用格式。
- 语言仅是语义偏好，不保证排除其他语言。
- 某些登录页面、受限出版物或反爬网站可能无法抓取正文，此时应使用“打开原文”。

后续保存功能将基于当前返回的标题、URL、作者、发布日期、highlights、正文和抓取时间建立独立的网页知识来源记录。
